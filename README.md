# Dandiya Partner Invite 2026

An interactive, heartfelt, and fun Dandiya Partner Invitation web experience for Navratri.

## Features
- **Cute Character Companion**: 100% custom-generated expressions using Google's latest **Nano Banana** model (Peeking, Happy, Sad, Crying, and Celebrating).
- **Runaway "No" Button**: The "No" button mischievously dodges the cursor with hilarious excuses, while the "YES" button grows larger with every attempt.
- **Exit-Intent Detection**: If the mouse moves toward the top-right corner to close the window, an emotional crying kitten alert pops up pleading not to leave!
- **Instant WhatsApp Reply Hook**: When the recipient clicks "YES", a customized acceptance message is ready to be sent to the inviter on WhatsApp.
- **Pass Generator**: Download a customized official "Dandiya Partner Pass" certificate with both names.
- **Synthesized Dhol Beats**: Authentic rhythmic Dandiya beats and stick clacks synthesized with Web Audio API (zero audio files needed, works offline).
- **Custom Link Generator**: Any visitor can generate their own customized shareable link (`?to=...&from=...`).
- **Zero Native Unicode Emojis**: Crisp, cohesive inline SVGs only.

## 1-Click Vercel Deployment
This project is configured for zero-setup instant deployment on Vercel:
1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import this repository.
4. Framework Preset: **Other** (Root directory: `./`).
5. Click **Deploy**! Live in ~15 seconds.
